# Evil Garden

Projeto desenvolvido pela **Liminal Studios** para o curso superior de **Tecnologia em Jogos Digitais da Faculdade de Tecnologia de Americana (FATEC Americana)**.

---

## Sobre o Projeto

**Evil Garden** é um projeto acadêmico de desenvolvimento de jogos digitais desenvolvido pela Liminal Studios para a disciplina ministrada pelo Prof. Cleberson, na Faculdade de Tecnologia de Americana.

O projeto tem como objetivo aplicar conhecimentos práticos de desenvolvimento de jogos, abrangendo diferentes áreas da produção, incluindo game design, programação, arquitetura de software, interface e experiência do usuário, level design e design de áudio.

O desenvolvimento do projeto representa a aplicação prática dos conhecimentos adquiridos durante o curso de Tecnologia em Jogos Digitais.

---

## Gameplay e Design

### Gênero

Ação, Roguelike, Sobrevivência e Troll Game.

### Perspectiva

Top-down 2D.

### Proposta

Evil Garden tem como foco a exploração e o enfrentamento de desafios por meio de mecânicas de combate, gerenciamento de recursos e progressão de dificuldade.

A experiência busca trabalhar diferentes aspectos do desenvolvimento de jogos, proporcionando uma gameplay baseada em tomada de decisões, exploração e adaptação aos desafios apresentados.

### Principais Sistemas

#### Game Feel e Balanceamento

Implementação de respostas visuais, físicas e sonoras com o objetivo de proporcionar maior responsividade aos controles e sensação de impacto durante as ações do jogador.

O balanceamento das mecânicas busca estabelecer uma progressão adequada de dificuldade, mantendo o desafio e a fluidez da experiência.

#### UI/UX

Desenvolvimento da interface com foco em clareza, organização das informações e facilidade de utilização.

Os principais objetivos incluem:

- Organização das informações de gameplay;
- Feedback visual das ações do jogador;
- Menus intuitivos;
- Legibilidade dos elementos da interface;
- Comunicação clara do estado do jogo.

#### Level Design

Construção dos ambientes considerando diferentes situações de exploração e combate.

O level design busca trabalhar:

- Rotas estratégicas;
- Áreas de exploração;
- Zonas de respiro;
- Áreas de conflito;
- Progressão de desafios;
- Posicionamento estratégico de elementos.

#### Sonoplastia

Utilização de efeitos sonoros para complementar a experiência de gameplay e contribuir para a construção da atmosfera do jogo.

Os efeitos de áudio são utilizados principalmente para:

- Feedback de ações;
- Combate;
- Impactos;
- Interações;
- Ambientação;
- Imersão.

## Execução e Build

### Requisitos

Para executar o projeto a partir do código-fonte, é necessário possuir:

- Unity instalada;
- Git instalado;
- Computador compatível com os requisitos da Unity.

Recomenda-se utilizar a mesma versão da Unity utilizada durante o desenvolvimento para evitar problemas de compatibilidade.

### Clonando o Repositório

Clone o repositório utilizando o comando:

```bash
git clone https://github.com/GabrielNazario1227/Game_Evil_Garden_.git
```

## Executando o Projeto

1. Abra o **Unity Hub**.
2. Selecione a opção **Add** ou **Open** para adicionar um projeto existente.
3. Selecione a pasta do projeto.
4. Aguarde a Unity carregar e importar os arquivos necessários.
5. Localize a cena principal do jogo.
6. Abra a cena principal.
7. Clique no botão **Play** no editor da Unity para iniciar o jogo.

## Executando uma Build

Caso uma versão compilada do jogo esteja disponível, ela poderá ser encontrada na seção **Releases** do repositório.

Nesse caso, não é necessário abrir o projeto através da Unity. Basta realizar o download da versão correspondente ao sistema operacional e executar o arquivo disponibilizado.
